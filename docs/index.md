# 파일패널 지원

화면 가장자리나 메뉴 막대에서 바로 꺼내 쓰는 macOS 파일 변환기, **파일패널** 지원 페이지입니다.

## 사용 방법

1. 화면 가장자리의 주황색 탭을 누르거나, 메뉴 막대의 변환 아이콘을 누릅니다.
2. 변환할 이미지나 문서를 끌어다 놓거나, 드롭 영역을 눌러 파일을 고릅니다.
3. 원본 형식은 자동으로 인식됩니다. **변환 형식**과 **저장 위치**를 고른 뒤 **변환**을 누릅니다.

## 자주 묻는 질문

**앱을 실행했는데 창이 보이지 않아요.**
파일패널은 Dock 아이콘 없이 동작하는 앱입니다. 화면 가장자리의 탭이나 메뉴 막대 아이콘을 확인해 주세요. 둘 다 꺼져 있다면 Finder나 Spotlight에서 앱을 다시 열면 설정 창이 열립니다.

**탭 위치를 바꾸고 싶어요.**
탭을 위아래로 끌어서 옮길 수 있습니다. 왼쪽/오른쪽 가장자리와 모니터는 탭을 우클릭 → 설정에서 바꿀 수 있습니다.

**워드 문서의 서식이 일부 달라져요.**
문서 변환은 macOS 내장 문서 엔진을 사용합니다. 머리글·바닥글, 각주, 복잡한 표 등 일부 레이아웃은 원본과 다를 수 있습니다.

**앱을 완전히 종료하려면요?**
탭이나 메뉴 막대 아이콘을 우클릭 → 파일패널 종료를 선택하세요.

# FilePanel Support

FilePanel is a file converter for macOS that lives on the edge of your screen and in the menu bar.

- **How to use:** Click the orange tab on the screen edge (or the menu bar icon), drop images or documents, choose an output format and a save location, then click Convert.
- **Can't find the app?** FilePanel has no Dock icon. Look for the tab on the screen edge or the menu bar icon. Relaunching the app from Finder or Spotlight opens Settings.
- **Contact:** [GitHub Issues](https://github.com/carryHoon/filepanel/issues)
- **Privacy:** FilePanel collects no personal data. See the [Privacy Policy](./privacy/).
