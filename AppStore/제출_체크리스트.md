- 대소문자 규칙 (혼동 주의):
  - 사람이 보는 이름: **carryHoon** (Mac mini 이름, GitHub 계정)
  - 웹 주소 도메인: **carryhoon**.github.io (도메인은 원래 소문자)
  - 번들 ID: com.**carryhoon**.filepanel (관례상 소문자, 출시 후 변경 불가)
- App Store Connect에서 앱을 만들 때 번들 ID 목록에서 이 값을 고르세요. (Xcode 자동 서명이 개발자 계정에 등록해 둠)

### 2. Apple Developer Program
- 유료 멤버십(연 129,000원 / $99) 가입 상태인지 확인
- Xcode Signing에서 해당 팀 선택 (현재 팀 ID: C24GVMX59M)

### 3. App Store Connect에서 앱 만들기
- 나의 앱 → ＋ → 새로운 앱 → 플랫폼 **macOS**
- 이름: 파일패널 / 기본 언어: 한국어 / 번들 ID: 1번에서 정한 값 / SKU: 예) filepanel-mac

### 4. 웹 페이지 URL (GitHub Pages로 게시됨)
- **개인정보 처리방침 URL**: https://carryhoon.github.io/filepanel/privacy/ (원문: `docs/privacy.md`)
- **지원 URL**: https://carryhoon.github.io/filepanel/ (원문: `docs/index.md`)

### 5. 앱 정보 입력
- `앱스토어_정보.md`의 설명·키워드·부제 붙여넣기
- 카테고리: 유틸리티 (보조: 생산성)
- 연령 등급: 설문에 모두 "없음" → 4+
- **앱 개인정보 보호 → "데이터를 수집하지 않음"** 선택

### 6. 스크린샷 (최소 1장, 최대 10장)
- 허용 크기(16:10): 1280×800, 1440×900, 2560×1600, 2880×1800 중 하나
- 추천 구성:
  1. 가장자리 탭이 펼쳐진 변환 화면 (파일 올린 상태)
  2. 메뉴 막대 팝오버
  3. 형식 메뉴가 열린 모습 (이미지·문서·아이콘 형식)
  4. 변환 완료 (초록 "✓ 변환 완료" + Finder에서 보기)
  5. 설정 창

### 7. 빌드 올리기
1. Xcode 상단 실행 대상: **Any Mac (Apple Silicon, Intel)**
2. Product → **Archive**
3. Organizer → Distribute App → **App Store Connect** → Upload
4. App Store Connect에서 빌드 선택 → `심사_메모.md`의 영어 메모를 "App Review 정보 → 메모"에 붙여넣기 → 심사 제출
