# 개인정보 처리방침

개인정보 처리방침 원문은 **`docs/privacy.md`** 한 곳에서만 관리합니다. (두 곳에 두면 내용이 어긋날 수 있어서)

- 게시 주소 (App Store Connect → 앱 정보 → 개인정보 처리방침 URL): **https://carryhoon.github.io/filepanel/privacy/**
- 지원 URL (App Store Connect → 버전 정보 → 지원 URL): **https://carryhoon.github.io/filepanel/**

방침을 고칠 때는 `docs/privacy.md`를 수정하고 main에 푸시하면 1~2분 뒤 페이지에 반영됩니다.
앱이 데이터를 다루는 방식이 바뀌면(예: 네트워크 기능 추가) **앱 업데이트 전에** 방침과 App Store Connect의 "앱 개인정보 보호" 답변을 먼저 갱신하세요.
