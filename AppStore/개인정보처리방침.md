# 파일패널 개인정보 처리방침

시행일: 2026년 9월 29일

파일패널(이하 "앱")은 사용자의 개인정보를 소중히 여기며, 다음과 같이 개인정보를 처리합니다.

## 1. 수집하는 개인정보
앱은 **어떠한 개인정보도 수집하지 않습니다.**
이름, 이메일, 기기 식별자, 위치, 사용 기록 등 어떤 정보도 수집·저장·전송하지 않습니다.

## 2. 파일 처리 방식
- 사용자가 선택하거나 끌어다 놓은 파일은 **사용자의 Mac 안에서만** 변환됩니다.
- 변환된 파일은 사용자가 지정한 폴더에만 저장됩니다.
- 앱은 인터넷에 연결하지 않으며, 파일이나 그 내용을 외부로 보내지 않습니다.
- 앱은 macOS App Sandbox 안에서 실행되며, 사용자가 직접 선택한 파일과 폴더에만 접근합니다.

## 3. 기기에 저장되는 설정
앱의 사용 편의를 위해 다음 설정만 사용자 기기 안에 저장됩니다. 외부로 전송되지 않습니다.
- 가장자리 탭의 위치(왼쪽/오른쪽, 세로 위치, 모니터)
- 가장자리 탭·메뉴 막대 아이콘 표시 여부
- 로그인 시 자동 실행 안내를 보여줬는지 여부

## 4. 제3자 제공 및 추적
앱은 광고, 분석 도구, 제3자 SDK를 사용하지 않으며, 사용자를 추적하지 않습니다.

## 5. 아동의 개인정보
앱은 개인정보를 수집하지 않으므로, 아동의 개인정보도 수집하지 않습니다.

## 6. 방침 변경
이 방침이 바뀌면 이 페이지에 변경 내용과 시행일을 게시합니다.
