## Notes (English – paste this)

FilePanel is a menu bar / screen-edge utility that converts image and document files locally on the Mac. It has no Dock icon by design (LSUIElement), similar to other menu bar utilities.

WHERE TO FIND THE APP
- On first launch, the app asks whether to open at login (the login item is only registered if the user agrees), and then automatically expands the conversion panel.
- A small orange tab is attached to the left edge of the main display. Click it to open or close the conversion panel. The tab can be dragged up and down.
- A menu bar icon (two circular arrows) opens the same conversion view in a popover.
- Relaunching the app from Finder/Spotlight while it is running opens the Settings window. Right-click the tab or the menu bar icon for Settings and Quit.

HOW TO TEST
1. Click the tab (or the menu bar icon).
2. Drag any image (e.g. a .webp, .heic or .png file) or document (.docx, .rtf, .txt) onto the panel, or click the drop area to choose files.
3. The source format is detected automatically. Choose an output format (e.g. PNG, JPEG, PDF).
4. Click "저장 위치 / Save location" and choose a folder (e.g. Downloads), then click the convert button.
5. The button turns green ("변환 완료" = Done) and "Finder에서 보기" reveals the converted files.

PRIVACY & SANDBOX
- All conversion happens on-device with Apple frameworks (ImageIO, PDFKit, NSAttributedString). The app makes no network connections and collects no data.
- The app is sandboxed and only accesses files and folders the user explicitly selects or drags in (com.apple.security.files.user-selected.read-write).
- Launch at login uses SMAppService and is off by default; it is enabled only after the user agrees in the first-launch prompt or turns it on in Settings.

The UI is in Korean. Key labels: 파일 변환 = File Conversion, 변환 형식 = Output format, 저장 위치 = Save location, 변환 = Convert, 설정 = Settings, 종료 = Quit.

## 메모 (한국어 요약 – 참고용)

- Dock 아이콘 없이 화면 가장자리 탭 + 메뉴 막대 아이콘으로 동작하는 유틸리티
- 첫 실행: 로그인 시 자동 실행 동의 창 → 변환 패널 자동으로 펼쳐짐
- 테스트: 탭 클릭 → 파일 끌어다 놓기 → 결과 형식 선택 → 저장 위치 선택 → 변환
- 모든 변환은 기기 안에서 처리, 네트워크·데이터 수집 없음, 샌드박스 적용
- 로그인 시 자동 실행은 기본 꺼짐, 사용자 동의 시에만 등록
